## Download

| Platform | Get it |
| --- | --- |
| iPhone and iPad | App Store, linked from [boundless.moe](https://boundless.moe) |
| Android | Google Play, or the APK from [the latest release](https://github.com/BoundlessReader/Boundless/releases/latest) |
| Mac | The DMG from [the latest release](https://github.com/BoundlessReader/Boundless/releases/latest) |

Updating from an earlier version keeps your library, progress and settings. On Android, stick to one channel: an APK from here can't update a Google Play install, or the other way round.

## What's in it

Read from the sources you add, or from your own CBZ, CBR, EPUB and text files. Comics can be paged, long strip or right to left, with a page curl if you miss paper. Novels scroll or turn like a book, in whatever font and size suit your eyes at 2am.

Download chapters for the commute. Log what you read on AniList, MyAnimeList, Kitsu, MangaUpdates, MangaBaka, Shikimori or Bangumi. Your library and your place in every series follow you from phone to tablet to Mac.

Sites behind Cloudflare mostly just work, so you'll rarely see a "checking your browser" page. App Lock, incognito reading and parental controls are there when you want them.

## Help and feedback

- **Something broken?** [Open a bug report](https://github.com/BoundlessReader/Boundless/issues/new?template=bug_report.yml). The error log in Settings helps a lot.
- **Have an idea?** [Suggest a feature](https://github.com/BoundlessReader/Boundless/issues/new?template=feature_request.yml).
- **Missing a site?** [Request a source](https://github.com/BoundlessReader/Boundless/issues/new?template=source_request.yml).
- **Questions and chat:** [Discussions](https://github.com/BoundlessReader/Boundless/discussions) or [Discord](https://discord.gg/BDbk4AYV72).
- **Anything private:** support@boundless.moe.

Please search existing issues first, and add a thumbs up to the one that matches yours rather than opening a new one.

## About this repository

This repository hosts release builds, release notes and issue tracking. The source code is not public. Release builds are obfuscated.

Security issues should be reported privately, see [SECURITY.md](SECURITY.md).
